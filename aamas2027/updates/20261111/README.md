Это существующая рабочая рукопись «Do Optimized Personas Predict New Respondents?»,
а не автоматически обновлённая версия по ноябрьским экспериментам.

Ноябрьское продолжение A18 пока представлено отдельными исследовательскими заметками:

- [Агрегаты CPU Slurm 27702 за 11 ноября](A18_OPT80_SUMMARY.json).

Новый контроль: CMA-MAE, random и coordinate, 3 seed × 3 folds = 27 ячеек,
одинаковый лимит 70 кандидатов, только ранее использованные OPT80.
Средний RPS: 0.118534815 / 0.118718431 / 0.118590691 соответственно.
Средняя разность CMA-MAE минус random −0.000183616, минус coordinate −0.000055876.
CMA-MAE выигрывает лишь в 1/3 seed против каждого контроля.
Это exploratory-проверка на уже использованных участниках, без новых LLM-вызовов,
свежего TEST, подтверждающих интервалов или вывода об эквивалентности методов.
Данные участников и индивидуальные прогнозы в эту публикацию не включены.

Исходная общая рабочая копия сохранена без изменений. Публикация выполнена
из отдельной копии той же ветки; в коммит включены только текст, зависимости
сборки, PDF и эти агрегированные заметки.
