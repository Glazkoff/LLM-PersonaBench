# Results contract

Every experiment writes here and only here. Analysis scripts read only from here. If a
number is in the paper, a file in this tree produced it.

## Layout

```
results/
  cells/<cell_id>/          cell_id = {arm}__{model_slug}__c{cluster}__s{seed}
    config.json             fully resolved config (arm yaml + models.yaml row + panels.yaml + budget)
    run_meta.json           see schema below
    history.jsonl           one line per candidate evaluation, in evaluation order
    best_genotype.json      the selected genotype (selected on the optimisation panel only)
    eval_frozen.json        every metric on the frozen evaluation panel, computed once
    per_respondent.json     per-respondent RPS_cal / RPS_raw / S0 arrays for the bootstrap
    belief_probs.npz        (git-ignored) simplices: eval (200,60,5), and transfer (200,180,5) if run
    status.json             {"state": pending|running|completed|failed_oom|failed_readout|failed_other|stuck, "updated": iso8601, "attempt": int, "slurm_job_id": str, "message": str}
  baselines/c{cluster}__s{seed}.json      non-LLM floors/ceilings on the same panels (model-independent)
  baselines/splitnoise_c{cluster}.json    20-redraw split-noise floor per baseline
  aggregates/               tables and figure data produced by scripts/analysis/*.py; always regenerable
  MANIFEST.sha256           sha256 of every tracked file, regenerated by scripts/analysis/manifest.py
```

## Tracked vs ignored

Tracked: every `.json`, `.jsonl`, `.yaml`, `.md`, `.csv` under `results/`. Ignored: `*.npz`,
`*.npy`, `*.log`. Ignored files are regenerable from the tracked genotype + the model, and are
bundled for the reproducibility archive with a SHA-256 manifest (`arr2026/BUNDLE_REGENERATE.md`
shows the format).

## Rules

1. A cell directory is created with `status.json = pending` by `queue.py submit`, before any
   job starts. A missing directory means the cell was never scheduled.
2. Writes are atomic: write to `<file>.tmp`, then `os.replace`. A reader never sees a partial file.
3. Nothing is deleted. A failed attempt keeps its `history.jsonl` under `attempts/<n>/`.
4. `eval_frozen.json` is written exactly once per cell by `src/optim/frozen_eval.py`. If it
   must be recomputed (bug fix), the old file moves to `attempts/` and `STATUS.md` records why.
